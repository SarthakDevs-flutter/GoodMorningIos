Put your app icon here:

  app_icon.png   ← 1024 × 1024 pixels, square PNG

Rules:
- One file only, named exactly: app_icon.png
- Do NOT round the corners — iPhone adds rounded corners automatically
- Use a solid background (no transparency) for best results on iOS

After adding the file, run on Mac (or double-click Desktop "아이콘 적용"):

  cd ~/Desktop/means_of_grace
  flutter pub get
  dart run flutter_launcher_icons
  flutter run

Then delete the app from iPhone home screen and install again to see the new icon.
